# JaVatheCruD

A simple Java Console CRUD application built using Object-Oriented Programming (OOP) principles, Data Access Object (DAO) pattern, and MS SQL Server Stored Procedures.

## Features

- **Create**: Add new users to the database using Stored Procedures.
- **Read**: Retrieve and display all registered users.
- **Update**: Modify existing user details securely by ID.
- **Delete**: Remove users from the database.
- **Architecture**: Separated Model, DAO, and Main UI logic for clean and maintainable code.

## Tech Stack

- **Language**: Java 19
- **Database**: MS SQL Server (JDBC Driver: `mssql-jdbc`)
- **Design Pattern**: Data Access Object (DAO)
- **Environment**: Visual Studio Code (VS Code)

## Prerequisites

1. Java Development Kit (JDK 19 or higher) installed.
2. MS SQL Server configured with SQL Server Browser and TCP/IP enabled.
3. Microsoft JDBC Driver for SQL Server configured in your Java project.
